# MILA Landing Page Anatomy Design Brief

## Objective

Create a visual anatomy blueprint for the MILA landing page.

The goal is to show the **structure, storytelling flow, and conversion journey** of the landing page in the style of a premium product anatomy poster.

Use the provided reference image as inspiration:

- numbered sections
- callout lines
- labels
- explanatory notes
- structured product breakdown

The result should explain **how the landing page works**, not just redesign individual sections.

---

# Design Direction

## Brand Concept

MILA is a personal styling intelligence platform.

The landing page should communicate:

- Personal style discovery
- AI-assisted styling
- Fashion intelligence
- Personalized recommendations
- Premium editorial experience

The feeling should be:

> Luxury fashion editorial + modern SaaS product experience

---

# Visual Language

Follow MILA's existing design system.

## Colors

Use:

- Paper Cream background
- Porcelain surfaces
- Ink typography
- Champagne Gold accents
- Muted neutral tones

Avoid:

- Generic SaaS blue gradients
- Startup dashboard aesthetics
- Heavy glass effects
- Excessive floating cards
- Loud marketing visuals

---

# Anatomy Structure

The landing page should be divided into 7 major sections.

---

# 01 — THE COVER

## Purpose

The first impression.

Communicate:

"What is MILA and why should users care?"

## Include

- Main headline
- Supporting description
- Primary CTA
- Trust statement
- Product preview

## Visual

Show:

- Generated look preview
- Style dossier document
- Personalized recommendation example

The user should immediately understand:

"MILA creates a personal style experience based on me."

---

# 02 — PRODUCT VISUAL

## Purpose

Show the actual product experience.

Do not represent the product only through text.

Show the artifact:

- Generated outfit
- Hair recommendation
- Makeup recommendation
- Styling explanation
- Color palette

The product should be visible.

---

# 03 — STYLE DOSSIER

## Purpose

Explain the personalized intelligence behind MILA.

Show the user's personal profile.

Include:

- Color season
- Silhouette
- Face shape
- Hair preferences
- Style direction

Example:

```
STYLE DOSSIER

Season:
Soft Autumn

Silhouette:
Balanced

Palette:
Camel
Olive
Chocolate

Direction:
Warm Minimal
Elegant
```

---

# 04 — COLOR INTELLIGENCE

## Purpose

Highlight MILA's fashion intelligence.

Show:

- Seasonal color system
- Palette recommendations
- Color swatches
- Styling relationship

Example:

```
COLOR PROFILE

Soft Autumn

Best:
Warm neutrals
Earth tones
Muted colors

Avoid:
Cool contrasts
Harsh tones
```

Color should be treated as information, not decoration.

---

# 05 — DAILY STYLING EXPERIENCE

## Purpose

Explain how users interact with MILA daily.

Show the styling flow:

```
Weather
+
Occasion
+
Wardrobe
+
Personal Profile

↓

MILA creates your look
```

Include:

- Outfit
- Hair
- Makeup
- Weather adaptation
- Wardrobe suggestions

---

# 06 — TRUST & PRIVACY

## Purpose

Build confidence before asking users for personal information.

Show:

```
Your Face
Your Wardrobe
Your Data

Protected by Design
```

Communicate:

- Privacy
- Security
- User ownership
- Control

---

# 07 — START YOUR DOSSIER

## Purpose

Final conversion section.

Include:

- Main CTA
- Pricing
- FAQ
- Trust reassurance

Preferred CTA:

"Start Your Dossier"

Avoid generic:

"Get Started"

The CTA should describe the experience users receive.

# Typography

Use:

## Display

Elegant serif typography.

Used for:

- Hero concepts
- Major headings
- Editorial moments

## Supporting

Clean sans-serif typography.

Used for:

- Descriptions
- Labels
- Explanations

Maintain:

- Large hierarchy
- Comfortable spacing
- Minimal uppercase usage

---

# Design Principles

## 1. Product First

Show the actual MILA experience.

Avoid explaining everything with marketing text.

---

## 2. Editorial, Not Corporate

The page should feel like:

A fashion dossier.

Not:

A startup landing template.

---

## 3. Calm Confidence

Use:

- whitespace
- typography
- material feeling
- subtle details

Avoid:

- urgency
- excessive badges
- aggressive conversion patterns

---

## 4. Modern SaaS Structure

Include SaaS best practices:

- clear value proposition
- visible product
- benefits
- trust
- conversion path

But maintain MILA's premium identity.

---
